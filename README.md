# home-soc-detection-lab
Home soc detection lab project using private and localised environment with the clear intention of educational purposes, this project tests the use of SIEM such as wuzzah against penetration attacks. 

The tools used shall mainly concise of Cloud Virtual Machine using Oracle Cloud Free Tier as well as localised virtual machine using UTM

This project consists of 3 virtual machines:
- Cloud VM Ubuntu Linux 1 (Wuzzah SIEM)
- Cloud VM Ubuntu Linux 2 (Victim)
- Local VM Kali Linux (Attacker)

Kali Linux shall attack the victim device in an attempt to penetrate it while the SIEM shall be used in order to detect, protect and eradicate the attack
